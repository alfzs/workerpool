# Contributing to workerpool

## Требования

- Go 1.26+ (см. `go.mod`)
- Git

## Начало работы

```bash
git clone git@github.com:alfzs/workerpool.git
cd workerpool
go build ./...
```

## Тесты

```bash
go test -race ./...
```

Тесты покрывают конкурентные инварианты (изоляция тенантов, лимиты
семафоров, graceful shutdown) — запускайте с `-race` локально и в CI.

## Стиль кода

Проект следует стандартным соглашениям Go (`gofmt`, ясные doc-комментарии
на экспортированных идентификаторах, ранний возврат вместо вложенных
`if/else`). Перед PR прогоните:

```bash
gofmt -l .
go vet ./...
```

## Процесс PR

1. Форкните репозиторий и создайте ветку от `main`.
2. Внесите изменения, добавьте/обновите тесты для нового поведения.
3. Убедитесь, что `go build ./...` и `go test -race ./...` проходят.
4. Опишите в PR *что* меняется и *почему* — ссылка на issue, если есть.
5. Обновите [CHANGELOG.md](CHANGELOG.md) в разделе `[Unreleased]`, если
   изменение видимо для пользователей пакета.

## Обратная связь

Баги и предложения — через [GitHub Issues](https://github.com/alfzs/workerpool/issues).
